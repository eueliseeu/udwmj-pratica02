# Prática 02 - Desenvolvimento Web & JavaScript

Este repositório contém as atividades práticas referentes à **Prática 02**, com foco na introdução à linguagem **JavaScript**, manipulação básica e integração com **HTML5** e **CSS3**.

## Estrutura de Arquivos e Exercícios

* **`pratica02e01.html`** — **Exercício 01**
  * Introdução e primeiras interações com JavaScript no HTML.

* **`pratica02e02.html`** — **Exercício 02**
  * Uso de scripts integrados/internos na página HTML.

* **`Ex3/`** — **Exercício 03**
  * **`pratica02e03.html`**: Estrutura HTML do exercício.
  * **`pratica02e03.js`**: Inclusão de scripts externos utilizando o comando `alert("Olá mundo!!! Arquivo Externo!");`.

* **`Ex4/`** — **Exercício 04**
  * **`pratica02e04.html`**: Estrutura da página.
  * **`pratica02e04.css`**: Folha de estilo CSS externa para layout e visual.
  * **`pratica02e04.js`**: Lógica em arquivo JavaScript separado para interação com a página.
